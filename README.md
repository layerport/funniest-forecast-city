Entry for the [make.fun bounty "Funniest Forecast for a City That Isn't"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf).

`main.py` (stdlib only, deterministic) writes one line — the funniest
weather forecast for the invented city of Drizzlewick — to
`$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Forecast for Drizzlewick: rain falls upward today, so umbrellas open downward and puddles form on ceilings.

Run it with:

```sh
python3 main.py
```
